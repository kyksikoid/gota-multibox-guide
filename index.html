Getting Started

This script integrates real-time visual tracking, frustum culling, and automation macros into Gota.io via Tampermonkey. To toggle the primary interface, click the floating MULTIBOX pill located at the top-right border of your viewport or tap your configured menu bind (default: Right Shift).

Interface Navigation UI / Controls

The overlay consists of a draggable control center and a floating target anchor:

Number SlidersClick or drag sliders to alter delay timings (50ms - 3000ms).

Auto-Rev Mechanics Computer Vision

Auto-Rev performs edge detection and circle extraction directly on the WebGL frame buffer to compute target cell mass and trajectory.

Crucial Game Settings

  • Disable player nicknames in the game settings.
  • Disable mass indicators inside cells.
  • Disable custom skins (must be flat color).
  • Keep your zoom and camera static while locked.

Failure to disable these settings will disrupt the color threshold scanner and generate false split alerts.
